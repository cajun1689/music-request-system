# Gaslight Director Review

Prepared November 14, 2026. **Offline review candidate, not a deployed show update.** The working club show, band show, DJ Bridge 1.14.0, startup services, patch and wing/APC assignments have not been changed. No third-party plugin was purchased or installed.

The saved library already contains 26 movements per mover zone, 28 rhythms per family and 20 palettes. This upgrade adds deliberate contrasts and useful operating states. More motion is not always a better look: keep the wide shapes readable, move the visual emphasis around the room, and use dimmer density and color contrast for energy.

## What is built

- **Five banks, twenty authored looks:** Calm, Groove, Drive, Peak and Breakdown. Four looks per bank, with a five-minute rotation inside the bank. Bank selection previews immediately; AUTO ON starts rotation. The candidate does not infer energy from audio or change banks automatically.
- **Four new movement shapes in each mover zone:** Wide Dwell, Mirrored Low Arc, Wing Curtain and Corner Glide. Thirty-two-beat measures at Div4 for Stage and Div8 for Dance/Garage give nominal 64/128-second cycles at 120 BPM. Long travel times keep the large pan ranges readable; repeated points deliberately dwell in an area. Existing Slow Drift/Horizon Drift are reused with shape-specific scales where a quieter shape works better. Higher energy banks do not speed up the same movement. Floor/wall/ceiling coverage is a room check, not something guaranteed by the pattern names.
- **Eight new dimmer patterns in the four primary families:** Velvet Pulse, Paired Breath, Two Step, Soft Comet, Wing Exchange, Triplet Wave, Staggered Hold and Slow Rise. All have spatial phase offsets. Relative values range from 0 to -85; they retain a light floor even at full effect depth. Energy banks scale the depth below the operator's starting level. Direct fader changes stop automatic depth adjustment for that family until RELEASE REVIEW and re-arm.
- **Twelve new two-color palettes:** Cobalt Amber, Magenta Ice, Red Cobalt, Violet Gold, Cyan Ruby, Emerald Magenta, Indigo Teal, Fuchsia Amber, Blue Rose, Lime Violet, Turquoise Copper and Deep Blue Amber. Stage and Dance have distinct color roles, with the room PARs supporting that contrast. Bar stays warm in these palettes and has explicit zero dimmer modulation in the new All PAR rhythm cues. A different existing rhythm can still affect Bar.
- **Wheel-aware color storage:** RGB fixtures fade in Part 0; mechanical wheels use static slots derived from the saved Lightkey profiles, stored with zero fade in Part 1. Requested hues and actual wheel-slot RGB/DMX choices are recorded in `generated/build-manifest.json`. Wheels cannot reproduce every RGB hue; their physical travel still needs observation.
- **Single-screen review controls:** Layout 94 has five energy buttons, rotation ON/HOLD, separate Next Movement/Next Dimmer/Next Color, Auto/Manual colors, status, test-song input, Exit to Club and twelve fixed palette buttons. Exit cancels the review automation and opens existing Home, retaining the current output until the operator starts the original controls. Active bank and timer state update in the layout. No page/executor/MIDI assignment is made.
- **Read-only audit and stored-value verifier:** audit all known group masters, executor pages and active sequences; preserve full group/page/controller XML rather than relying on truncated plugin source getters. The verifier checks the newly stored phaser values, preset references, IMRELAX centers and color values without starting playback.

The twelve palettes are in the candidate's song-color choices, independent of the five-minute movement/dimmer timer. **Actual track events are not routed to this candidate yet.** TEST SONG CHANGE calls the same candidate action that a future approved routing update will call. Color pad selection switches candidate colors to manual; COLORS AUTO explicitly resumes them. There is no automatic all-white selection. The existing first-song white opening remains unchanged in DJ Bridge and is excluded from these banks.

The candidate preserves Grand Master, group masters, base intensity/shutters and movement size. Stopped/zero movement and dimmer families remain off. Existing dedicated side-strobe Sequence 117 is only asked to alternate its approved patterns; neither its base master nor its effect depth is raised. White hits, blackout, fast shutter strobe, prism and gobo changes remain deliberate operator actions in the existing show.

## Review-only installation

1. At the booth, back up the **current** XT show and capture the current operator changes. Run `Audit Current Show.lua` from an unused plugin slot. It writes JSON plus matching native group/page/controller XML into grandMA3's ImportExport folder. Bring those files back for review. Audit failures are recorded in JSON and must be checked; missing readback is not a passing result.
2. Resolve the actual group membership and scaling masters. Historical sources disagree about Group 13 (Room Depth versus Dedicated Strobes). The startup capture previously read only Groups 1–8, while the newer wing layout also uses collective PAR and dedicated-strobe masters. Do not restore or reassign Groups 10/13 based on the old manifest alone. Use the new native exports and the current assignment screen.
3. Inspect active position and intensity owners. Legacy Aim Sequence 140 and zone sequences 601–606, 611–616, 621–626 predate the IMRELAX forward calibration. Only the calibrated base 11 and movement family 101 were previously verified. Retire or repair the legacy options after readback. Likewise, All PAR 114 overlaps Bar 115, while Room Depth 116 overlaps mover rhythms 111–113. Resolve active overlaps before preview; group membership overlap alone is not a defect.
4. Work in a separate copy named **Gaslight_Club_Director_Review**, with live output/session isolated for programming and review. Preserve `Gaslight_Club_Live` as the startup show. Stop review playbacks before installing. Do not load the review show onto an operating live XT.
5. Import `generated/Install Director Review.lua` into an unused plugin slot **other than 940**. It preflights every destination, requires the calibrated IMRELAX base centers, and refuses a different show name. It programs in Blind, creates new objects only and neither starts playback nor saves. An unexpected partial failure requires restoring the backup, not rerunning the installer over partially created objects.
6. Run `generated/Verify Director Review.lua` from another free slot. Its native stored-value checks have been prepared but **have not yet been run inside grandMA3 2.4.2.2**. A successful offline Lua test does not establish native API/storage compatibility.
7. Start the desired existing review base/movement/rhythm families using the current club controls, then stop timer 160 and turn existing track colors OFF. Leave Bar-only 115 and Room Depth 116 off. Open a Layout window and choose Layout 94. Select GROOVE to preview, then AUTO ON if desired. The director refuses active legacy position owners or conflicting automations. It does not turn up the room itself.
8. Review all banks, every new movement, every palette on both IMRELAX and the other wheel fixtures, and every rhythm at low and normal brightness. Check actual forward coverage, width, speed, wheel travel, steady Bar, phase distribution, side-strobe levels and touchscreen fit. Test Next controls, manual fader changes, stopped families, HOLD/RESUME, repeated clicks, a five-minute transition and show reload. HOLD stops future changes; it **does not freeze physical movement or pulses**. RELEASE REVIEW cancels the review timer and retains the current output. Resume the original system explicitly using its existing controls.

Reserved new objects: Plugin 940; Layout 94; Macros 9401–9429; Appearances 9401–9420; movement presets 2.601–612 and cues 27–30 in 101/102/103; rhythm presets 1.601–632 and cues 29–36 in 111/112/113/114; RGB color presets 4.601–612, wheel presets 4.621–632, and palette cues 21–32 in 121. The installer refuses occupied destinations before editing anything. Keep the current base show backup for rollback.

## Live integration still required

After the native and room checks, merge the selected looks into the current show rather than replacing it with this review copy. Keep only one rotation owner and one audible-track color route. DJ Bridge's normal second-song transition should enter Groove, with a manual energy override for the lighting operator. Preserve the single white opening, owner lease, audible-deck debounce, Serato/native CDJ modes and manual color override. Route song events through the approved color controller, without counting a muted load as a new song. A track event arriving during a look change must be deferred/deduplicated rather than dropped.

Keep wing Page 1 brightness primary. APC faders remain a separate page-following bank, pads remain fixed colors, and the dedicated physical automation buttons remain separate. Add bank selection and HOLD/RESUME to spare controls only after fresh mapping readback. No primary feature may depend on the APC being present. Add clear tempo freshness, source, automation and opening-state feedback to the final touchscreen/Bridge status; stale tempo should retain the current look at the last tempo, with a visible manual fallback. Test this behavior before promising it.

Verify native CDJ/A9 and Serato/DVS at the venue, including disconnects, track changes during transitions and multiple DJ Macs. BPM following is not absolute beat/phrase position. Do not claim automatic musical breakdowns, drops or bar-accurate launches until a real phase/phrase source works in both playback modes. Native phasers continue to use MA's existing A9 Club BPM speed master; this pack does not create another music receiver.

Finish with fresh XT local save/export/reload and default club startup checks. Update the printed operating guide using screenshots of the final deployed touchscreen and physical assignments, not this review layout. Keep the simple band show independent. The Mac legacy startup helpers stay in place until the existing DJ Bridge migration is verified; this pack does not change that cutover.

## Plugins considered

Checked vendor pages November 14, 2026. Nothing is required to run this candidate: native MA phasers, MAtricks and the custom controls cover the automated club workflow.

- **MA3 Pro Plugins Live Grid — $85:** the strongest optional addition for operator nights. Scene recall, subgrouping, transitions and a global hold can make deliberate live operation easier. The vendor lists MA 2.0–2.5 compatibility; test an isolated copy on 2.4.2.2 before incorporating it. It must not create a second automated playback layer over the custom director. [Vendor](https://www.ma3-pro-plugins.com/)
- **MBLightarts Color Picker V2 — €39.90:** useful color grids, sweeps and splits. Its current V2.2.3 is listed as last tested with MA 2.5.1.0; confirm a compatible 2.4.2.2 build before purchase. The existing fixed color pads plus the new authored palettes may already be simpler for this room. [Vendor](https://mblightarts.de/ma3-color-picker-generator)
- **MA3 Pro Plugins MIDI Encoders:** optional only if the APC's actual encoder message mode and spare controls warrant it. It requires relative MIDI encoders; current APC assignments are absolute CC. Keep the wing encoders primary. Size Fader duplicates functionality already handled by selector 901. The same vendor's Color Picker Pro is still marked Coming Soon, so it is not an available recommendation. [Vendor](https://www.ma3-pro-plugins.com/)
- **Palgen-GMA3:** an open-source harmony generator worth evaluating in a copy for palette inspiration, not randomizing live room colors. No third-party code is copied into this pack, and compatibility has not been verified on this XT. [Project](https://github.com/PeramatoG/Palgen-GMA3)

Keep ShowKontrol optional for native CDJ metadata. It does not solve the user's Serato requirement; do not make it another required tempo owner.

## Rebuild and validation

From the repository root, run `python3 grandma3-director-review/build.py`, then run `npm test` inside `rekordbox-agent`. The generated files are committed so this does not require Python on the XT. CI rebuilds the assets and checks for drift.

The offline suite executes the actual Lua controller/installer against simulated MA objects and checks conflict guards, brightness limits, stopped-family behavior, manual overrides, five-minute scheduling, stale timer cancellation, family-specific Next controls, palette selection, installer preflight and read-only audit JSON. It checks generated pattern envelopes, Bar zeros and valid static wheel slots. The native verifier is syntax-checked offline; its API/storage readbacks and every physical/UI/music integration test above remain pending. No offline test measures light output or guarantees a native MA command is accepted.
